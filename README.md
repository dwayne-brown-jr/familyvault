# FamilyVault

Financial legacy and protection app — the things a household should have written down before anyone needs them.

**Status:** in development (Vercel)

---

## Features

- **Digital emergency binder** — accounts, policies, and documents in one place
- **Prioritized financial action plan** — what to fix first, not an undifferentiated checklist
- **Insurance gap analysis** — coverage you have vs. coverage the household needs
- **529 calculator** — education funding projections
- **Letter-of-intent generator**
- **Shared household access** — both partners see the same picture
- **AI assistant** for navigating it

## Stack

Next.js 16 · React 19 · Supabase · Anthropic SDK · Recharts
